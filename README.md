# ✅ Vue Todo App

A modern **Todo Application** built with **Vue 3 + TypeScript**, featuring:  
- State management with **Pinia**  
- Routing with **Vue Router**  
- Component-scoped and global CSS  
- Icons powered by **oh-vue-icons**  
- Loading spinner for async feedback  
- A fun **AI Chatbox widget** (ChatGPT-style demo)  

This project was migrated from a previous **React Todo App** and restructured for a production-ready Vue 3 environment using Vite.  

---

## 🚀 Features

- **Add, Edit, Delete Todos** – clean CRUD flow  
- **Toggle Completed / Pending** status  
- **Todo Details Page** with Vue Router  
- **Reusable Form Component** for todos  
- **Loading Spinner** for async states  
- **Floating AI Chatbox** (demo AI replies)  
- **TypeScript support** for type-safety  
- **Scoped + Global Styles** split across components  

---

## 🛠️ Tech Stack

- [Vue 3](https://vuejs.org/) with `<script setup>` syntax  
- [TypeScript](https://www.typescriptlang.org/)  
- [Vite](https://vitejs.dev/) – lightning fast dev server & build tool  
- [Pinia](https://pinia.vuejs.org/) – state management  
- [Vue Router](https://router.vuejs.org/) – routing system  
- [oh-vue-icons](https://oh-vue-icons.js.org/) – icon system

## ⚙️ Installation & Setup

```bash
# 1. Clone the repository
git clone https://github.com/stevo1935/vue-todo-app.git
cd vue-todo-app

# 2. Install dependencies
npm install

# 3. Run development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build
npm run preview

🤖 AI Chatbox

The app includes a floating AI chatbox (bottom-right 💬 button).

Expands only when messages are sent.

Stores short-lived conversation in memory.

Fake AI replies are generated for demo purposes.
